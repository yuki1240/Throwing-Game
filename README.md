# BallGame（壁面投影ボール当てゲーム）

壁にプロジェクターで映像を映し、ボールが当たった位置に花や演出を出す設置用アプリです。
Kinect v2 の深度だけを使って、ボールが壁に当たった位置を見つけます。

- Unity 6（6000.4.0f1）／URP／新しい Input System のみ
- シーンは `Calibration`（校正）→ `Game`（ゲーム）の順
- 画面（UI）は実行時に 1920×1080 の Canvas で組み立てます

---

## 1. はじめに用意するもの

| もの | 説明 |
| --- | --- |
| Kinect v2 と PC 用アダプター | 深度センサー |
| Kinect for Windows Runtime 2.0 | `Kinect20.dll` が入ります（Microsoft のサイトから入手） |
| プロジェクター | 壁に映します |

Kinect が無い PC でも動きます。そのときは 320×240 の「模擬深度」に自動で切り替わり、Game 画面のクリックがボールになります。

---

## 2. 校正のしかた（現場の画面だけで完結）

Unity で `Assets/Scenes/Calibration.unity` を開いて再生します（ビルドしたアプリは最初にこの画面が出ます）。

1. **設置を選ぶ**
   - 「横に設置」（初期値）：Xbox ロゴが操作者側を向く置き方。画像の下が近く、上ほど遠い。
   - 「真下に設置」：壁の真下から上を見る置き方。画像の上が近く、下ほど遠い（見やすいように表示だけ上下を入れ替えます）。
   - 選んでいる方のボタンが緑になります。同じボタンを押し直しても四隅と基準は消えません。別の設置に切り替えたときだけ消えます。
2. **左のプレビューで四隅をタップ**
   - 左上 → 右上 → 右下 → 左下 の順にタップします。間違えたら「四隅をやり直す」。
3. **人がいない状態で「基準を録る」**
   - 30 フレーム録って、画素ごとの中央値を基準にします（全部 0 のフレームは数えません）。
4. **「ゲームへ」**

そのほかのボタン：

- **左右反転**（初期オン）：画像を左右反転します。四隅と基準も一緒に反転します。
- **入力源**：Kinect／模擬 を切り替えます。
- **壁からの距離**：これより壁から離れた物は無視します（初期 15cm、5〜80cm）。
- **リセット**：2 回押すと、四隅・基準・しきい値・左右反転・入力源・設置向きをすべて消して最初からにします。

校正は自動で保存され、Game から戻ったときと次回起動時に元に戻ります。
保存先は `Application.persistentDataPath/ballgame_calibration.bin` です。

---

## 3. ゲーム画面

- 四隅で囲った範囲が、背景画像いっぱいに引き伸ばされます（壁座標は左下 (0,0)、右上 (1,1)）。
- 壁の **下半分** に当たると **花**、**上半分** に当たると **演出** が出ます（境目は演出設定で変更可）。
- 上部の操作：背景の選択（◀ ▶）、ランダム、固定、切替間隔（初期 5 分、60 秒〜1 時間）、壁からの距離、校正へ戻る。
- **スペースキー** で、上部の操作・HIT 表示・校正へ戻るボタン・壁からの距離をまとめて隠します（もう一度押すと出ます）。
- 当たるたびに、Kinect 上の位置（0〜1）、壁の位置（0〜1）、Unity の画面座標をコンソールに出します。

---

## 4. 画像と演出の入れ替え

| 置き場所 | 内容 |
| --- | --- |
| `Assets/Textures/Backgrounds` | 背景画像。名前順に使います。入れると `Resources/BackgroundCatalog` が自動で更新されます（ビルド用）。 |
| `Assets/Textures/Flowers` | 花の画像（透過 PNG 推奨）。自動で Sprite として取り込みます。 |
| `Assets/BallGame/Settings/GameEffectSettings.asset` | 演出設定。Game シーンの `GameBootstrap` に割り当て済み。 |

演出設定（インスペクタで変更）：

- **flowerBoundary**：花と演出の境目（初期 0.5）
- **themes**：背景ごとの花（複数）と演出（複数）。`backgroundName` に背景のファイル名を書くとその背景に使います。
  演出を空にすると、背景 1 は輪・閃光・粒、背景 2 は二重・波紋・十字、背景 3 は渦・花びら・閃光粒です。
- 同時表示は最大 24、色は紫、表示倍率 1.25、再生 1 秒（すべて変更可）。演出は終わったら破棄します。

同梱の背景 3 枚と花 3 枚は動作確認用の仮の画像です。

## 5. 検知のしくみ（要点）

- 四隅の内側だけを見て、基準深度と今の深度を比べます。
- Kinect は壁に沿って見るので、奥行きの差ではなく「四隅の基準から作った壁の面までの垂直距離」で判断します。
- 基準を録るときに画素ごとの揺れ幅も記録し、しきい値は「ノイズ床（初期 45mm、校正画面で変更可）」と「揺れ幅×4」の大きい方にします。壁からの距離（初期 15cm）より遠いものは捨てます。
- 基準があった画素が 0 になったときは、赤外線が返らない物体として候補にします（基準を録る間に 0 になったことがある画素は除く）。
- しきい値を超えた点を芯にして、つながっている「しきい値の 6 割以上」の弱い変化も塊に含めます（ボールの縁を拾うため）。
- 3×3 で孤立した芯は捨て、4 連結の塊にします。塊の中で一番強い点がしきい値の 1.3 倍未満のもの、縦横の箱の 3 割未満しか埋まっていないまばらなものは捨てます。
- 面積 12 未満は捨て、24 以上は 1 フレームで採用、その間は 2 フレーム続いたら採用します。
- 変化画素が 4500 を超える、または縦横が 80 画素を超える塊があるときは「人」とみなし、ボールは出さず、去ったあと 0.5 秒待ちます。
- 同じ場所に留まった物体は出し続けません。ヒット位置は塊の重心です。

---

## 6. テスト

Unity の **Window → General → Test Runner → EditMode** で実行します。
校正の保存、設置の上下関係、背景の切替、花と演出の選択、壁の面までの距離、人サイズの除外を確かめます。

---

## 7. フォルダ構成

```
Assets/
  BallGame/
    Scripts/Runtime/   … ゲーム本体（Core / Depth / Detection / Session / Game / Effects / UI / Screens）
    Scripts/Editor/    … 背景カタログの自動更新、画像の取り込み設定
    Settings/          … 演出設定（ScriptableObject）
    Tests/EditMode/    … Edit Mode テスト
  Resources/           … ビルド用の背景カタログ
  Scenes/              … Calibration.unity / Game.unity
  Textures/            … Backgrounds / Flowers
```
